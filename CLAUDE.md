# Portfolio Terminal

Портфолио-проект: дашборд инвестиционного портфеля (frontend, React + TypeScript + Vite, моковые данные через MSW).

**Полное техническое задание — в [TZ.md](TZ.md). Прочитай его целиком перед началом работы.**

Правила:
- Работай по этапам из раздела 16 ТЗ; каждый этап — рабочая сборка и коммит.
- Финансовые расчёты — только чистые функции с unit-тестами (раздел 6.2); MSW-обработчики используют те же функции.
- Строгий TypeScript, без `any`; все строки интерфейса — через i18n (RU/EN).
- Сверяйся с анти-целями (раздел 3), прежде чем считать этап готовым.
